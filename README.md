# APP-002 — VR Catalog

Личный отборный каталог для Meta Quest 3 / Meta / Steam / PCVR.

Каталог разделяет четыре типа записей:

- **Игра**
- **Программа**
- **Мод / инструмент**
- **18+** — отдельная небольшая подборка, не смешанная с обычными программами

## Рабочая версия

https://setjip-spec.github.io/vr-catalog/

## Текущий milestone

**v0.2 — QLoader curated expansion**

Полная выгрузка QLoader используется только как источник кандидатов. В APP-002 не импортируются тысячи строк подряд: добавляются только сильные игры, полезные программы и небольшой отобранный 18+ раздел.

`data-5.js` содержит расширение v0.2: отсутствующие принятые игры, дополнительный research-tier, новые утилиты и отдельный тип 18+.

## Архитектура

```text
GitHub main                → канонический код и общий статический каталог
GitHub Pages               → пользовательский Web-интерфейс
Supabase MINI-APPS-CLOUD   → авторизация и персональное состояние APP-002
localStorage               → быстрый локальный кэш / миграционный fallback
Google BACKUP SAFE         → независимая disaster-recovery копия
```

Статические записи находятся в `data-*.js`. Пользовательские статусы, комментарии, сохранённые виды, фильтры, колонки и сортировка синхронизируются через Supabase.

## QLoader

Для новых записей поддерживается необязательная колонка **QLoader / язык**. Если подтверждён русский вариант, используется пометка `RUS`; если вариант нужно сверить — `проверить`.

## Правило разработки

Все доработки делаются только от текущей ветки `main`. Если меняется поведение продукта, сначала обновляется `docs/APP-002-TZ.md`, затем код, затем проверяется GitHub Pages.

Google Apps Script Web App для этого приложения не используется.
